# Changelog

All notable changes to Hush are documented here. Hush follows [semantic versioning](https://semver.org).

## 1.0.1 — 14 November 2026

- License agreement rewritten for business use: Single project and Unlimited projects tiers defined by production projects, one year of updates with continued use of the last version received, a 30-day refund window and a verification clause.
- README: the Composer repository address, a note on the installer's default primary color, the `make:filament-theme` steps and the update and license terms. The testing section, which only applies to the source repository, was removed.

## 1.0.0 — 14 November 2026

First release.

- Theme for every part of a Filament 5 panel: navigation, tables, forms, actions, modals, widgets, notifications and the auth pages, with Geist and Geist Mono.
- Three layouts: Classic, Inset and Sidebar.
- Six accent presets, plus any color string or Filament palette.
- Comfortable and compact density; sharp, default and rounded corners.
- Three dark mode shades: Default, Dim and Black.
- Optional per-user Appearance menu, stored in a cookie or on the user record, with a contract for custom stores.
- Branded split sign-in for the sign-in, registration, password reset, email verification and two-factor pages.
- Lucide icon set: swaps 217 of Filament's icons and bundles all 2,356 Lucide icons as `hush-lucide.{name}`.
- Brand mark for the collapsed sidebar in the Sidebar layout.
- Subtle motion with loading skeletons, off under reduced motion or with `withoutAnimations()`.
- Print styles.
- Precompiled stylesheet for panels without a theme, and a source stylesheet for custom Tailwind themes.
